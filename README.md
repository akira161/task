# Tasks — 並列タスク管理（ブラウザ / PWA）

依存ライブラリなし（Node.js 18+ のみ）。PC・スマホどちらのブラウザからも使え、データはサーバー側に一元保存されるので端末間で同期されます（5秒ごと＋画面復帰時）。

## 起動

```sh
npm start            # http://localhost:3000
```

起動時にアクセストークンが表示されます（`data/token` に保存。`TASK_TOKEN` 環境変数で指定も可）。
初回は画面でトークンを入力するか、`https://<host>/#token=<トークン>` を開くとログインできます（スマホにはこのリンクを送るのが簡単）。
スマホでは「ホーム画面に追加」でアプリとして使えます。

| 環境変数 | 既定 | 内容 |
|---|---|---|
| `PORT` | 3000 | 待受ポート |
| `TASK_TOKEN` | 自動生成 | アクセストークン |
| `DATA_DIR` | `./data` | データ保存先 |

> 外部公開する場合は、必ず HTTPS（リバースプロキシや Cloudflare Tunnel / Tailscale など）の背後に置いてください。トークンは平文で送られます。

## 入力

クイック入力欄（`n` `/` `Ctrl+K` で移動）に1行で入力して Enter:

```
資料作成 #仕事 !1 @明日 >doing
```

| 記法 | 意味 |
|---|---|
| `#名前` | プロジェクト |
| `!1`〜`!3` | 優先度（1=高） |
| `@today` `@明日` `@+3d` `@金` `@10/25` `@2026-10-25` | 期限 |
| `>todo` `>doing` `>waiting` `>done` | 状態 |

プロジェクトで絞り込み中は、そのプロジェクトに追加されます。

### 外部から追加（ショートカット等）

```
GET/POST  https://<host>/api/quick?token=<トークン>&text=<URLエンコード済み文章>
```

iOS/Android のショートカット、ブックマークレット、Alfred、`curl` などから呼べます。
アプリ内からは `https://<host>/?add=<文章>` でも追加できます。

## 並列タスクの管理

- **ボード**: 未着手 / 進行中 / 待ち / 完了。「進行中」に複数同時に置け、「待ち」で他人待ちを退避できます。
- **プロジェクト**: プロジェクトごとの列に並べ、各列で「進行中」の数が見えます。カードを別の列へドラッグするとプロジェクト移動。
- カードの ▶（進行中）/ ✓（完了）ボタンはスマホでもワンタップ。

## キーボード

`b`/`p` 表示切替 · `j`/`k` 選択 · `Enter`/`e` 編集 · `t` `s` `w` `x` = 未着手/進行中/待ち/完了 · `1` `2` `3` 優先度 · `Del` 削除 · `?` ヘルプ

## 開発

```sh
npm test
```

API: `GET/POST /api/tasks`, `PATCH/DELETE /api/tasks/:id`, `GET /api/rev`（`Authorization: Bearer <token>`）
